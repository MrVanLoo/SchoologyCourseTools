# Schoology toolkit

Read `HANDOFF.md` in full before doing anything. It is the build brief.

Rules that hold for every change:

- The Schoology format rules in `HANDOFF.md` section 3 were confirmed by live imports. Do not alter them.
- No Schoology API calls, no browser automation, no network access at run time.
- Never describe an untested import behavior as working.
- Run `tests/run_all.sh` before reporting anything as done.
- When finished, write `REPORT.md` as described in `HANDOFF.md` section 10.
